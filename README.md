## Main project

### [PETUNE](https://github.com/rivermh/petune)

ペットの生活・健康データを記録し、日々のケアに活用できるWebサービスです。

- Java / Spring Boot / Spring Data JPA
- Spring Security / OAuth
- MySQL / Flyway
- Thymeleaf / Tailwind CSS / JavaScript
- 施設検索、ペットプロフィール、ケア・健康・服薬・体重記録
- タイムライン、カレンダー、レポート、CSVエクスポート
